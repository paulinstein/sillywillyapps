# Silly Willy Brand Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A ChatGPT prompt sheet for the logo art and a one-page brand guide for Silly Willy Apps.

**Architecture:** A static folder with no build step. `brand/index.html` is one self-contained page (inline CSS, Google Fonts) that shows code mockups until the ChatGPT PNGs exist in `brand/logo/`, and switches to them when they do. A new git repo at `~/github_projs/sillywillyapps`, which the website can join later.

**Tech Stack:** HTML, CSS, Google Fonts (Fraunces, Caveat Brush, DM Sans).

**Spec:** `brand/DESIGN.md`

## Global Constraints
- Palette exactly: ink navy `#1F2A44`, crayon yellow `#FFD84D`, coral `#E8604C`, paper cream `#FBF6EA`.
- Don't draw final art in code. Mockups are labelled "stand-in until the ChatGPT art arrives".
- Copy is warm, a little self-mocking and fine for kids to read. No manifesto tone, no edgy jokes.
- Promise line: "No ads. Just fun things I like making."
- Money wording: no ads, ever; small optional purchases and pay-once games are fine.
- Logo files: `brand/logo/wordmark.png`, `brand/logo/sticker.png`, `brand/logo/monogram.png`, all with transparent backgrounds.

## Review Focus
- Phone width (375px): the page must not scroll sideways, and the palette and logo rows must wrap.
- Missing PNGs: the page shows the mockups, never a broken-image icon.
- Dark mode: logo cards stay on a cream "paper" background so the navy ink stays readable.
- The fonts fail to load: the fallback fonts still look intentional (serif, cursive, sans-serif).
- Colour contrast: body text is navy on cream, never coral on cream for small text.

- [ ] **Step 1:** Run `git init` in `~/github_projs/sillywillyapps`.
- [ ] **Step 2:** Write three prompts: wordmark (wide, about 2400×800), sticker (about 1600×900) and monogram (1024×1024).
