# sillywillyapps.com Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Astro site for sillywillyapps.com with Home, Apps, Blog (Markdown, tags, RSS) and About, in the Silly Willy brand, deployed to GitHub Pages by an Action.

**Architecture:** Astro static output at the root of the `sillywillyapps` repo. Blog posts are a content collection, apps come from one data file, and logos are imported from `brand/logo/` through `astro:assets`. Tests are `node --test` files that run against the built `dist/`, so every check is about what visitors actually get.

**Tech Stack:** Astro (current stable, via `npm create astro@latest -- --template minimal`), `@astrojs/rss`, `@astrojs/sitemap`, `@fontsource-variable/fraunces`, `@fontsource/dm-sans`, `@fontsource/caveat-brush`, Node 22, GitHub Actions (`withastro/action`).

**Spec:** `docs/superpowers/specs/2026-11-13-website-design.md` (brand rules: `brand/DESIGN.md`, `brand/index.html`)

## Global Constraints
- Palette: ink navy `#1F2A44`, crayon yellow `#FFD84D`, coral `#E8604C`, paper cream `#FBF6EA`. Coral is never used for small text on cream.
- No ads, analytics, trackers, cookies, or requests to any third-party host from built pages (fonts are self-hosted).
- Site URL `https://sillywillyapps.com`. The Dog Stories link is always `https://dogstories.sillywillyapps.com`.
- Copy follows the brand voice: "I" not "we", warm, a little self-mocking, no "ultimate/epic/revolutionary".
- Promise line, exactly: "No ads. Just fun things I like making."
- Posts with `draft: true` never appear in any page, tag page, RSS or sitemap.
- The wordmark is shown only on light backgrounds; in dark mode the header shows the sticker.
- Pages work at 375px width with no sideways scroll.
- Nothing is pushed or created on GitHub, and no DNS is changed, without Paul's go-ahead.

## Review Focus
- A post with no tags or no `cover` builds and renders without empty "Tags:" labels or broken images. (Task 3 test: `post without cover renders`; tags checked in Task 6)
- An app with no store links shows "Coming soon to the App Store and Google Play", not empty buttons. (Task 4 test: `app without store links says coming soon`)
- Fewer than three posts (only the welcome post at launch): the home page shows what exists, with no empty slots. (Task 4 test: `home lists only existing posts`)
- Dark mode: the header swaps to the sticker, and no navy-on-navy text. (Task 2 test: `dark header uses sticker`; contrast checked in the browser in Task 6)
- Large logo masters never reach visitors. (Task 2 test: `no logo master is shipped`)
